# Python Calculator Project

This is a simple command-line calculator written in Python. It supports basic arithmetic operations:

- addition (`+`)
- subtraction (`-`)
- multiplication (`*`)
- division (`/`)

The main entry point is `main.py`.

## Requirements

- Python 3.8 or newer
- No external packages are required.

## How to run

From the project directory, run:

```bash
python main.py
```

You will be guided through an interactive calculator session.

You can also use a one-shot command-line mode:

```bash
python main.py 2 + 3
```

This will print the result (`5.0`) and exit.
